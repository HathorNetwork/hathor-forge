# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2025-01-01

### Added

- Local Hathor fullnode management with one-click start/stop.
- Integrated CPU miner with real-time hash rate display.
- Multi-wallet support via the wallet-headless service.
- Built-in faucet for funding development wallets with HTR.
- Embedded block explorer for browsing blocks, transactions, and addresses.
- Real-time dashboard showing block height, hash rate, and service status.
- MCP server (port 9876) with 26 tools for AI-driven blockchain development.
- CLI mode (`hathor-forge-cli`) for headless operation without a GUI.
- Cross-platform support for macOS, Linux, and Windows (experimental).
- Nix-based development environment with reproducible builds.
- GitHub Actions CI/CD for all supported platforms.
